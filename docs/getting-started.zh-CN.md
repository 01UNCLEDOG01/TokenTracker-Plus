# TokenTracker Plus 普通用户上手指南

> 写给「我只是想看看我烧了多少 token」的你。不需要会编程、不需要命令行。

## 一、安装（Windows）

1. 打开 [Releases 页面](https://github.com/01UNCLEDOG01/TokenTracker-Plus/releases)，下载已发布最新版的 `TokenTracker-Setup.exe`；旧版可能带版本号。
2. 双击安装。安装向导会显示目录，可按需选择，不需要管理员权限。
3. 装完勾选启动，任务栏右下角会出现托盘图标；从托盘打开内嵌仪表盘。

就这么多。安装包自带完整的运行时：**不需要装 Node、不需要注册账号、不需要填 API Key、不连接任何云服务**。

## 二、第一次打开你会看到什么

- **仪表盘**：总花费、每日趋势、按模型/按工具的明细、项目归属、活动热力图。
- **会话页**：每一轮对话烧了多少 token、多快（tok/s）、花了多少钱，还能展开看子代理树。
- **限额页**：各家 AI 工具的额度窗口和重置倒计时。Cursor 通信暂时失败可回退同账户缓存；WorkBuddy 国内/国际版分开显示，奖励积分的悬浮明细会提示北京时间最早到期日和当日到期数量。
- **成就页**：65 枚成就 + 17 个称号，全部按你本机数据离线判定，解锁有 Steam 风格弹窗。
- **全球模型榜**：Artificial Analysis 和 AIHOT 双榜，评分与价格同页比较，各自缓存；缺失指标显示「—」，实测零保留。
- **福利指南**：53 家服务商；中文名全拼和英文品牌名取更靠前的名称统一按 A–Z 排序，可按分类、搜索和领取状态查找，每张卡保留官网、核对日期与来源。
- **服务状态页**：包含 OpenCode 官方状态；未知或读取失败会明确显示，不能当作正常。
- **用量范围**：标明本机/账户。普通单机使用默认本机；自行配置云实例、登录且同步和云读取可用后才可做临时只读比较，不改变上传偏好。
- **Codex 明细**：展开模型可查看 Standard / Fast / Ultrafast 的 token 和完整费用，包含缓存及长上下文。

它会自动扫描你电脑上装过的 55 款 AI 编码工具（Claude Code、Codex、Cursor、Qoder、Kimi……），读取它们本地留下的用量记录。**你什么都不用配置，历史用量也会被自动补齐。**

## 三、日常使用

- **开机自启**：托盘图标右键可以打开/关闭开机自启动，后台常驻、自动增量同步。
- **端口**：优先使用 `http://127.0.0.1:17680`，被占用时选择其他空闲端口；从托盘打开可进入实际地址。
- **刷新**：页面数据每分钟自动刷新；手动同步走托盘菜单的「立即同步」。
- **桌宠/悬浮窗/额度小组件**：都在托盘右键菜单里开关。
- **福利领取标记**：领取后手动确认。每日福利每天北京时间 00:00 提示「今日未领取」，每月福利在每月 1 日提示「本月未领取」；双周期卡片分别标记，一次性福利不会自动重置。选择每日/月度分类后，「已领取/待领取」按对应周期筛选；全部分类中双周期都确认才算整卡已领取。旧标记按原记录日期自动迁移，页面跨日或休眠回来会自动刷新。

## 四、可选配置（不配也完全能用）

绝大多数功能零配置。只有个别「限额卡」需要你手动给一次本地凭据，页面会明确提示缺什么：

| 功能 | 需要什么 | 怎么做 |
|---|---|---|
| Qoder 国际版限额卡 | 网页版 Cookie | 双击仓库根目录的 `Qoder-Intl-刷新Cookie.cmd`，按提示粘贴 |
| Qoder CN 限额卡 | 网页版 Cookie | 双击 `Qoder-CN-刷新Cookie.cmd` |
| 其他余额类卡片 | 个别需要对应平台凭据 | 卡片上会写明缺什么 |
| WorkBuddy / WorkBuddy AI 配额卡 | 无需任何配置 | 前提是对应桌面客户端正在运行（额度经客户端本地接口读取，含套餐与每日奖励额度）；客户端没开时该卡显示未连接，积分账本不受影响 |

这些凭据只保存在你自己电脑的用户目录里，TT-plus 不上传它们。

## 五、数据与隐私

- **全部数据只在你本机**：`C:\Users\<你>\.tokentracker\`（队列账本 `queue.jsonl`）。
- **只记数字，不记内容**：token 数、时间、模型名、估算费用。你的代码、提示词、对话正文不会被保存或上传。
- **备份**：设置页 → 本机数据备份，可以导出快照到另一台电脑（异机导入会先预览、只补缺失）。
- **加载与缓存**：共享 JS/CSS 和本地会话响应采用 gzip；服务先提供页面再复制运行文件和修复集成。会话页显示缓存快照时间并尝试后台更新，仍可手动刷新；旧格式或超过 24 小时的磁盘缓存自动重建。
- **TRAE CN**：桌面后台刷新会采集本机数据库与 WAL 中的增量用量，无需启用云端用量读取；重复刷新不会重复入账。
- **会话留存**：轻量 gzip 快照保存已采集的会话统计。原记录删除后仍可看这些数字，不能恢复未采集的聊天内容。

## 六、升级与卸载

- **升级**：下载新版安装包直接覆盖安装，数据不丢。设置页的「检查上游更新」只做提醒，不会自动下载安装。
- **卸载**：控制面板里卸载程序即可；如果想连数据一起清掉，再删 `~/.tokentracker` 目录。

## 常见问题

- **页面打不开？** 等 10 秒再试（首次启动在热身）；还不行就托盘右键退出后重新打开。
- **数字和我自己算的对不上？** 看「成本口径」：免费路由按官方刊例价计值（这是本 fork 的立场），未公开价格的模型只记 token 不编金额；标注「估算」的数字带 ≈ 号。
- **托盘没有图标？** 检查是否被系统折叠了（^ 小箭头里）；Windows 偶尔会藏新装的托盘应用。
