## 一、核心成就专题：本命模型 (The One / heart_model) 如何触发与升级

### 1. 为什么设计这枚成就？
在 AI 编码时代，很多开发者会频繁切换不同模型做对比。但真正有深度工程习惯的极客，往往会对某一款模型产生极高的默契与信仰（例如将绝大部分上下文与核心任务托付给 Claude Opus、DeepSeek-V4、Gemini Flash 或 GPT-4o）。**本命模型**正是用来加冕这种“弱水三千，只取一瓢饮”的极客专注力。

### 2. 触发前提门槛（Guardrail）
```javascript
if (seenModels.size >= 5 && totalTokens > 0)
```
- ⚠️ **必须至少使用过 5 款不同的模型**。
- **原因**：如果一个新用户刚装上软件只用过 1 款模型，该模型的占比在数学上天然就是 100%，这属于“没有选择的选择”，不是“忠诚/本命”。只有在你尝试过至少 5 款不同的模型后，依然将绝大部分算力倾注给某一个模型，系统才会正式激活本命模型的判定！

### 3. 计算公式
$$\text{本命模型用量占比} = \frac{\text{生涯用量第一名的单一模型总 Token}}{\text{所有模型生涯总 Token}} \times 100\%$$

- **分子**：历史累计 Token 消耗量最高的那一款具体模型；
- **分母**：你机器上所有模型的所有历史 Token 之和。

### 4. 升级品阶阈值
| 品阶 | 触发比例门槛 | 徽章视觉 | 极客段位说明 |
|---|---|---|---|
| **青铜阶 (Bronze)** | **$\ge 50.0\%$** | 青铜外环 + 纯净二值灰阶 | 一半以上的算力交给了本命，初步形成依赖与偏好 |
| **白银阶 (Silver)** | **$\ge 70.0\%$** | 白银流光外环 | 绝大部分生产力与工作流围绕该模型构建 |
| **黄金阶 (Gold)** | **$\ge 85.0\%$** | 灿金能量外环 | 极度专一，除非特殊场景否则不换基座 |
| **钻石阶 (Diamond)** | **$\ge 95.0\%$** | 钻石星冕外环 | 终极信仰！95% 以上的世界全由它一手铸造 |

## 二、成就全局设计体系与四阶升级机制

1. **单向不可逆升级 (Monotonic Tiers)**：
   成就阶位一旦达成解锁，**终生点亮，绝不降级**。每次达成新的阶位，系统均会永久记录初次晋升的时间戳（First Achieved Timestamp）。
2. **纯本地离线计算 (Local-First)**：
   所有 55 枚成就均通过直读本地队列（`queue.jsonl`）和会话历史进行即时重放，无需联网、无需登录、完全保障隐私。
3. **Steam 原生体验**：
   达成成就或升级时，支持多卡并发垂直堆叠 Toast 弹出，悬停独立冻结倒计时（Hover-to-Pause），并配有金属质感音效。
