## ✨ 주요 기능

- 🔌 **55개 도구 자동 연결(설정 불필요)** —— Claude Code / Codex / Cursor / Qoder / Kimi 등 55개 AI 코딩 도구의 로컬 로그를 자동 감지. 로그인·API 키·클라우드 불필요.
- 💰 **무료 모델도 정가로 계상** —— 업스트림의 `-free` → 0원 규칙을 거부하고, 무료 라우트도 공식 정가로 평가. 공짜로 쓴 가치를 한눈에 확인.
- ⚡ **밀리초 단위 tok/s 스트림** —— 청크별 지속 시간과 추론 토큰을 분리해 세션 단위 생성 속도를 정확히 측정.
- 🌲 **세션 계층 분석** —— 메인 세션 / 서브에이전트 / 도구 호출 단위로 비용이 큰 작업을 추적.
- 📊 **Lv0~Lv7 8단계 히트맵** —— 하루 30억 토큰 초과의 '특이점(Singularity)' 단계 포함. 2D/3D 동시 지원. 활성 표본이 8일 이상이고 P98.5 이상이면서 P95를 초과해도 Lv7이 됩니다.
- 🏆 **업적 65종 + 칭호 17종 완전 오프라인 판정** —— Steam 스타일 토스트, 3D 메달, Canvas 전투 보고서 내보내기. 같은 브라우저에서 확인한 최고 등급을 유지하며, 기존 캐시의 첫 화면에서도 등급이 내려가지 않습니다. 사용량과 비율은 현재 실측값을 표시합니다.
- 🪟 **Windows 데스크톱 통합** —— 트레이 상주, 펫, 쿼터 위젯. 설치 프로그램에 Node 동봉(빌드 불필요).
- 🌍 **글로벌 모델 순위 두 종류** — Artificial Analysis 지능 순위와 AIHOT 종합 순위를 전환하며 점수, 입력/출력/캐시 가격, 컨텍스트와 출력 속도를 비교합니다. 각각 별도 캐시와 상태가 표시된 스냅샷을 사용합니다. 없는 지표는 “—”로, 실제 0은 0으로 표시합니다. AIHOT 데이터는 Kazik(数字生命卡兹克) 님의 오픈소스 프로젝트 AIHOT(aihot.news)에서 제공되며, 이에 감사드립니다.
- 🎁 **프로바이더 특전 가이드** — 53개 서비스와 클라이언트의 가입 크레딧, 일일/월간 혜택, 무료 구간과 출석 포인트를 안내합니다. 초대 행사 카드에는 초대 링크, 모든 카드에는 공식 링크·확인 날짜·출처를 표시합니다. 중국어 이름의 전체 병음과 영어 브랜드명 중 먼저 오는 이름을 기준으로 모두 A–Z 순서로 정렬하며, 분류·검색·수령 표시를 지원합니다. 수령 알림은 베이징 시간 매일 00:00 또는 매월 1일에 초기화됩니다. 두 주기가 있는 카드는 각각 표시하고 일회성 표시는 유지합니다. 날짜 변경·절전 복귀 시 갱신하며 기존 기록의 날짜도 이전합니다.
- **쿼터와 서비스 상태** — 30개 쿼터/잔액 소스. Cursor는 일시적인 통신 오류 때 같은 계정의 유효한 캐시를 사용하고, 인증 만료는 재로그인을 안내합니다. OpenCode는 공식 서비스 상태를 표시합니다. WorkBuddy 중국판과 국제판 잔액은 분리하며, 기존 호버 상세에 베이징 시간 기준 가장 빠른 만료일과 당일 만료 크레딧을 소수까지 표시합니다.
- **Codex 속도별 내역** — 모델을 펼치면 Standard / Fast / Ultrafast의 실측 token과 캐시·긴 컨텍스트를 포함한 전체 단계별 비용을 볼 수 있습니다. 도구 카드와 전체 모델 화면은 같은 내역을 사용하며 총비용 계산도 일관됩니다.
- **사용량 범위와 읽기 전용 비교** — 로컬/계정 범위를 표시하며 기본은 로컬 데이터입니다. 직접 설정한 클라우드, 로그인, 동기화, 정상적인 클라우드 읽기가 모두 활성화된 경우에만 일시적으로 비교할 수 있습니다. 업로드 설정은 바꾸지 않고 계정 변경이나 동기화 해제 시 선택이 초기화됩니다.
- **세션 통계 보존과 로컬 백업** — Qoder 양쪽 에디션, MiniMax, Devin 등의 로컬 세션을 확인할 수 있습니다. 가벼운 gzip 스냅샷은 수집된 통계만 보존하며 원본 삭제 뒤에도 볼 수 있지만, 수집하지 않은 대화는 복구하지 못합니다. 설정에서 `.ttbackup`을 내보내고, 다른 PC에서 가져올 때는 미리보기 후 없는 데이터만 추가합니다.
- 🔒 **100% 로컬** —— 기록하는 것은 수치뿐. 코드와 프롬프트는 저장·전송되지 않습니다.

- **로딩 및 다크 모드 가독성** — 로컬 세션 응답을 gzip으로 압축하고 재구성 중 목록 결과를 재사용합니다. 디스크 캐시는 비동기 I/O, 버전 형식, 최대 24시간 유효 기간을 사용하며 이전 형식은 자동 재구성됩니다. 저장 시각 표시와 백그라운드 갱신을 시도하고 혜택 페이지의 글자·테두리·키보드 포커스 대비를 높였습니다. 시작 시 런타임 복사와 통합 복구 전에 페이지를 제공하며 공통 JS/CSS를 사전 압축하여 전송합니다.
- **백그라운드 사용량 수집** — 데스크톱 갱신으로 TRAE CN 로컬 DB/WAL, 플러그인 신호가 없는 OpenClaw 세션, Prime Agent를 수집합니다. Windows에서는 TRAE가 쓰는 동안 짧은 공유 읽기 보호를 사용합니다. 나중에 추가되거나 수정된 사용량은 차이만 반영하며, 미완료 행이 새 사용량을 막거나 중복 계산하지 않습니다. 클라우드 사용량 조회에는 별도 동의가 필요합니다. Trae 클라이언트는 2026-09 업데이트 이후 로컬 요청 로그에 캐시 필드를 기록하지 않으므로, TRAE CN의 캐시 적중률은 다른 소스에서 같은 모델로 측정한 중앙값으로 **추정**합니다(토큰 총량은 측정값 그대로, 비용도 같은 추정치로 계산).

## ⚡ 빠른 시작

> **실행 환경**: 소스에서 실행하려면 Node.js **20+**가 필요합니다. SQLite 소스(opencode/zcode/loomy/trae 등)는 Node.js **22.5+**(내장 `node:sqlite` 사용) 또는 `sqlite3` 명령어 설치가 별도로 필요합니다. Windows 설치 프로그램에는 Node가 포함되어 있습니다.

**Windows는 빌드 불필요**: [Releases](https://github.com/01UNCLEDOG01/TokenTracker-Plus/releases)에서 `TokenTracker-Setup.exe`를 내려받아 설치하세요. 처음이라면 [입문 가이드](./docs/getting-started.zh-CN.md)(중국어)를 먼저 읽어보세요.

```bash
git clone https://github.com/01UNCLEDOG01/TokenTracker-Plus.git
cd TokenTracker-Plus
npm install
node bin/tracker.js   # 첫 실행: 훅 자동 설치 + 동기화 + Dashboard 열기
node bin/tracker.js status   # 55개 도구 연결 상태
node bin/tracker.js doctor   # 진단
```

로컬 Dashboard는 Windows 데스크톱판이 기본 `http://localhost:17680`, CLI `serve`는 기본 `7680`입니다. 지원 도구 전체 목록은 [중국어 README](./README.md#-支持的-ai-工具列表55-款)를 참고하세요(CLI / VS Code 확장 / IDE 총 55종).

## 💰 과금과 히트맵

`cost = Σ(tokens × 정가)`. LiteLLM 공식 요금 + 로컬 재정의. 미공개 가격 모델은 금액을 지어내지 않고 토큰만 기록. 히트맵은 P30 / P55 / P75 / P88 / P95 / P98.5 분위 + Lv7(≥30억 토큰/일) 8단계.

## 🔒 프라이버시

로컬 사용량 수집에는 계정이나 클라우드가 필요 없습니다. 쿼터·잔액은 해당 서비스에, 모델 순위·서비스 상태는 공개 정보에 접속합니다. 자체 클라우드 동기화는 명시적인 설정이 필요합니다. [개인정보 방침](./docs/PRIVACY.md)을 참고하세요.

토큰 수·시각·모델명·추정 금액 같은 수치만 로컬 `~/.tokentracker/`에 기록합니다. 프롬프트·응답·코드 본문은 저장·전송하지 않습니다. 쿠키/키가 필요한 것은 일부 쿼터 카드뿐이며 핵심 기능에는 불필요합니다. WorkBuddy 쿼터 카드(두 에디션 모두)는 데스크톱 앱이 실행 중일 때만 읽힙니다(플랜 + 일일 보너스 크레딧).
