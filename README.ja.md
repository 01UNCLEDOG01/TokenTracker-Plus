## ✨ 主な特徴

- 🔌 **ゼロ設定で 55 ツールに自動接続** —— Claude Code / Codex / Cursor / Qoder / Kimi など主要 55 ツールのローカルログを自動検出。ログイン不要、API キー不要、クラウド不要。
- 💰 **無料モデルも定価で計上** —— 上流の `-free` → 0 円ルールを拒否し、無料ルートも公式定価で評価。タダ乗りした価値がひと目でわかる。
- ⚡ **ミリ秒の tok/s ストリーム** —— チャンク単位の継続時間と推論トークンを分離し、セッション単位の生成速度を正確に計測。
- 🌲 **セッション階層を掘り下げ** —— メイン会話 / サブエージェント / ツール呼び出し単位で高コスト操作を特定。
- 📊 **Lv0〜Lv7 の 8 段階ヒートマップ** —— 1 日 30 億トークン超の「シンギュラリティ」階層を含む。2D / 3D 両対応。 活動日のサンプルが 8 日以上あり、P98.5 以上かつ P95 を超える場合も Lv7 になります。
- 🏆 **実績 65 種 + 称号 17 種を完全オフライン判定** —— Steam 風トースト、3D メダル、Canvas 戦績エクスポート。同じブラウザーで確認済みの最高ランクを保持し、古いキャッシュの初回表示でも降格しません。使用量と比率は現在の実測値を表示します。
- 🪟 **Windows デスクトップ統合** —— トレイ常駐・ペット・クォータ浮窗。インストーラーに Node 同梱でビルド不要。
- 🌍 **2 つのグローバルモデルランキング** — Artificial Analysis の知能ランキングと AIHOT の総合ランキングを切り替え、スコア・入出力/キャッシュ価格・コンテキスト・出力速度を比較。個別のキャッシュと状態表示付きのスナップショットに対応し、欠損値は「—」、実測の 0 は 0 と表示します。AIHOT のデータは Kazik（数字生命卡兹克）氏のオープンソースプロジェクト AIHOT（aihot.news）によるもので、ここに感謝します。
- 🎁 **プロバイダー特典ガイド** — 53 のサービス・クライアントの新規クレジット、毎日/毎月の特典、無料枠、チェックイン特典を掲載。招待企画のあるカードには招待リンク、全カードには公式リンク・確認日・出典を表示。中国語名のピンイン全文と英語ブランド名のうち先に来る名前を使い、全カードを A–Z 順に統一。カテゴリ、検索、受取済みマークに対応します。 受取マークは北京時間の毎日 00:00 または毎月 1 日にリセットします。両方の周期があるカードは別々に記録し、一度限りのマークは保持。日付変更やスリープ復帰時に更新し、旧記録の日付も移行します。
- **クォータとサービス状態** — 35 のクォータ/残高ソース。 Cursor は一時的な通信障害時に同一アカウントの有効なキャッシュを使用し、認証期限切れは再ログインを案内。OpenCode は公式サービス状態を表示。WorkBuddy の中国版と国際版は残高を別々に扱い、既存のホバー詳細に北京時間で最初の失効日とその日に失効するクレジットを小数付きで表示します。
- **Codex の速度別内訳** — モデルを展開すると Standard / Fast / Ultrafast の実測 token と、キャッシュ・長いコンテキストを含む全費用が見られます。プロバイダーカードと全モデル表示は同じ内訳を使い、総費用の計算は一貫しています。
- **用量の範囲と読み取り専用比較** — ローカル/アカウントの範囲を明示し、通常はローカルデータを表示。自分でクラウドを設定し、ログイン・同期・クラウド読み取りが有効な場合のみ一時的に比較できます。アップロード設定は変更せず、アカウント変更や同期停止時に選択をリセットします。
- **セッション統計の保持とバックアップ** — Qoder の両版、MiniMax、Devin などのローカルセッションを確認。軽量 gzip スナップショットは収集済みの統計だけを保持し、元ファイル削除後も参照可能ですが、未収集の会話は復元できません。設定で `.ttbackup` を書き出し、別 PC への取り込みはプレビュー後に不足データだけを追加します。
- 🔒 **100% ローカル** —— 記録するのは数値だけ。コードやプロンプトは保存も送信もされません。

- **読み込みとダークモード** — ローカルのセッション応答を gzip 圧縮し、再構築中は一覧を再利用します。ディスクキャッシュは非同期 I/O・バージョン付きで、最大 24 時間有効です。旧形式は自動再構築し、保存時刻の表示とバックグラウンド更新を試みます。特典ページの文字、枠線、キーボードフォーカスも見やすくしました。 起動時はランタイムのコピーと連携修復より先にページを提供し、共通 JS/CSS は事前圧縮して転送します。
- **バックグラウンド収集** — TRAE CN のローカル DB/WAL、プラグイン通知がない OpenClaw セッション、Prime Agent をデスクトップ更新で収集します。Windows では TRAE の書き込み中に短時間の共有読み取り保護を使います。後から補完・修正された使用量は差分で反映し、未完了の行で新しい使用量を止めたり二重計上したりしません。クラウド使用量取得には別途許可が必要です。Trae クライアントは 2026-09 の更新以降ローカルのリクエストログにキャッシュ項目を書かなくなったため、TRAE CN のキャッシュヒット率は他ソースで同じモデルを使った実測値の中央値から**推定**します（トークン総数は実測のまま、費用も同じ推定で算出）。

## ⚡ クイックスタート

> **環境要件**：ソースから実行するには Node.js **20+** が必要です。SQLite データソース（opencode/zcode/loomy/trae など）は、Node.js **22.5+**（組み込みの `node:sqlite` を利用）または `sqlite3` コマンドの導入が別途必要です。Windows インストーラーには Node を同梱しています。macOS 向けユニバーサルインストーラーも Node を同梱し、macOS 13+ の Apple silicon / Intel Mac で動作します。

**Windows / macOS はビルド不要**：[Releases](https://github.com/01UNCLEDOG01/TokenTracker-Plus/releases) からダウンロードしてインストールするだけです。Windows は `TokenTracker-Setup.exe`、macOS は `TokenTracker-plus-1.26.0.dmg` を「アプリケーション」へドラッグ。初めての方は[はじめてのガイド](./docs/getting-started.zh-CN.md)（中国語）へ。macOS 版は未署名のため、初回起動に「開発元を検証できません」と出たら右クリック →「開く」、または `xattr -cr /Applications/TokenTracker-plus.app` を実行してから開いてください。

> 🍎 **macOS ネイティブクライアント（1.26.0 から TT-Plus 自前のビルド）**：ネイティブ SwiftUI のメニューバー形式を維持（ユニバーサルバイナリ、Apple silicon / Intel 対応）、UI は 6 言語（簡体字 / 繁体字 / 英 / 日 / 韓 / 独）。**ローカルファースト**で、クラウドアカウント・サインイン・OAuth の画面はありません。ページメニューが 13 の fork ページをカバーし `tokentracker://open?path=` ディープリンクに対応、デスクトップペットは 7 体（庚戌 / 猫也 を含む）。アップデート確認は本リポジトリの Releases のみを参照します（アセット名 `TokenTracker-plus-<version>.dmg`）。WidgetKit ウィジェットも同梱します（サマリー / ヒートマップ / トップモデル / リミットの 4 種。ad-hoc 署名 + サンドボックス、App Group 不要）。デスクトップのクォータウィンドウと 35 プロバイダー分の limits カバーは本バージョンに含まれます。

```bash
git clone https://github.com/01UNCLEDOG01/TokenTracker-Plus.git
cd TokenTracker-Plus
npm install
node bin/tracker.js   # 初回起動：Hook 自動設置 + 同期 + Dashboard オープン
node bin/tracker.js status   # 55 ツールの接続状態
node bin/tracker.js doctor   # 診断
```

ローカル Dashboard は Windows / macOS デスクトップ版が既定で `http://localhost:17680`、CLI の `serve` は既定で `7680`。対応ツールの全リストは[中国語版 README](./README.md#-支持的-ai-工具列表55-款)を参照（CLI / VS Code 拡張 / IDE の 55 種）。

## 💰 課金とヒートマップ

`cost = Σ(tokens × 定価)`。LiteLLM 公式料金 + ローカル上書き設定。未公開価格のモデルは金額を捏造せずトークンのみ記録。ヒートマップは P30 / P55 / P75 / P88 / P95 / P98.5 の分位点 + Lv7（≥30 億トークン/日）の 8 段階。

## 🔒 プライバシー

ローカル用量の収集はアカウントやクラウド不要です。クォータ・残高は各プロバイダー、ランキングとサービス状態は公開情報へ通信します。自前クラウド同期は明示的な設定が必要です。[プライバシー方針](./docs/PRIVACY.md)も参照してください。

数値（トークン数・タイムスタンプ・モデル名・推定金額）のみをローカルの `~/.tokentracker/` に記録。プロンプト・応答・コード本文は保存も送信もされません。Cookie やキーが必要なのは一部のクォータカードだけで、コア機能には不要です。WorkBuddy のクォータカード（2 版それぞれ）はデスクトップアプリの実行中にのみ読めます（プラン + 毎日の報酬クレジット）。
