## 一、审计原则与统一量纲
1. **主排序量纲**：**单月（30 天）稳定可白嫖的等效人民币价值（¥/月）**。
2. **一次性/活动类福利**：按等效商业面额并入同档门槛；若活动明确截止日，附注当期爆发收益。
3. **折算定价基准**：
   - **现金代金券/真金白银**：取官方充值面额（如基元律动、硅基流动、蚂蚁百灵）；
   - **平台积分/额度**：优先按站内**官方标准月度套餐或充值包**折算（如华为码道标准版、电信 TeleAgent、团结 Cowork、MiniMax Code、豆包工作口径 B、讯飞 Loomy）；
   - **免费直用/限速模型**：以行业顶级商业基准 API（如 OpenAI / Anthropic / 智谱官方）输入输出标准资费，加权日可用额度折算。
