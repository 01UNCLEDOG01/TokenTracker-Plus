# 福利卡折算价值审计（2026-11-12 定谳 · 2026-11-13 增补修订）

## 一、审计原则与统一量纲
1. **主排序量纲**：**单月（30 天）稳定可白嫖的等效人民币价值（¥/月）**。
2. **一次性/活动类福利**：按等效商业面额并入同档门槛；若活动明确截止日，附注当期爆发收益。
3. **折算定价基准**：
   - **现金代金券/真金白银**：取官方充值面额（如基元律动、硅基流动、蚂蚁百灵）；
   - **平台积分/额度**：优先按站内**官方标准月度套餐或充值包**折算（如华为码道标准版、电信 TeleAgent、团结 Cowork、MiniMax Code、豆包工作口径 B、讯飞 Loomy）；
   - **免费直用/限速模型**：以行业顶级商业基准 API（如 OpenAI / Anthropic / 智谱官方）输入输出标准资费，加权日可用额度折算。

### 1. Agent Router（扣费实测与站主定谳：粉色超大额档）
- **实测样本**：2026-11-07 01:41 调用 `gpt-6-astra`。
  - 扣费日志：消费 **$0.719328**。
  - 上下文：输入 3,531 tokens，缓存 310,509 tokens（31 万大上下文），输出 1,260 tokens。
  - 站内公式：输入 $10/M、缓存 $2/M (0.2x)、输出 $50/M (5x)。
- **可用耐久度**：每日签到赠送 **$25** 站内额度。
  - 每天可支持跑满此类 31.4 万 tokens 超大上下文请求：`$25 ÷ $0.719328 ≈ 34.75 次/日`！
  - 每日可用长文本吞吐量高达 1,000 万 tokens 级。
- **真实商业含金量**：
  - 对标官方同级模型牌价（输入 $2.5/M、缓存 $1.25/M、输出 $10/M）：
    本次请求真实商业 API 成本 = `3,531×$2.5 + 310,509×$1.25 + 1,260×$10 = $0.4095`。
  - 站内美元含金量系数 = `$0.4095 ÷ $0.719328 ≈ 56.9%`。
- **等效人民币价值与站主定谳**：
  - 每日签到 $25 × 56.9% = **$14.23/日** 真实商业算力（汇率 7.23 折合 **¥102.88/日**）。
  - 单月（30天）全勤累积价值：**¥3,086/月**！
  - **站主拍板定谳**：虽然实测折算金额极高，但由于**模型是否存在掺水未知**，且**平台存在不可忽视的稳定性风险（此前曾有多日连续不可用/空回历史）**，故不升到最高琥珀档（`amber`），**正式定谳升至粉色档（`rose` · 超大额赠送）**。
